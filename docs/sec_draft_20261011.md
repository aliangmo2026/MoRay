# 1. 设计目标与原则
1.1 目标
面向安全运营的智能体平台：感知（日志/流量/EDR）→ 认知 → 决策 → 执行全链路，人工可介入、可审计、可回滚。
以“不误伤、不降级放行、风险不悬置”为第一优先级，智能上限让位于安全下限。
1.2 核心原则
非全闭环：LLM 仅作辅助研判，处置权限按动作分级；高危不可逆动作强制人工确认（HiTL）。初期 HiTL 为主，误报率达标后逐级放权。
抗幻觉：C 层输出强制结构化 JSON + 证据溯源 ID，禁止裸自然语言结论。
fail-safe / fail-closed：任何环节异常默认升级人工，绝不静默放行。
可回滚 + 可审计：动作带 TTL 与 undo；GR 与 EXEC 双独立哈希链。
数据飞轮：执行结果与人审结论反哺 θ 标定与知识库，但须去污染、滞后、可回滚。
分层解耦为主、直调为特例：跨层默认事件总线；仅 C.Out→D 求值单跳直调，白名单可关。
# 2. 总体架构
四层主链 + 横切机制 + 审计与飞轮。分层映射：S=P感知，A=C+D认知决策，R=X执行；横切 K=内核调度、MEM=记忆、GR=护栏、TI=威胁情报。

```
[日志/流量/EDR]→ P:采集降噪 → alert
C:Enrich(TI/CMDB) → Hyp(≥2 含 benign) → Evd(id 溯源) → Collide → Out{JSON}
├ 快道 L0(规则/小模型)  |  慢道 L1/2(大模型 ReAct)；CRIT 缺省 → 慢道
↓ 直调 ≤200ms 白名单单跳; outbox 同帧 → outcome; 开关可回纯总线
D:DSL(P0..P9, 四层消解) ⊕ GATE(score≥θh ∧ cf≥θcf ∧ GR=∅) → ACT{lvl,ttl}
↓ cmd
X:PLAY(PRECHECK→EXEC→VERIFY→COMMIT | ↘ROLLBACK)
回执矩阵 → outcome; 超时查状态优先; ROLLBACK 败 → P0 冻结
横切: K(PQ 硬分带/背压/熔断豁免 undo)  MEM(簇级沉淀三闸/LKG)
GR(五环谓词/fail-closed/永不降级/AL 豁免单)
审计: GR + EXEC 双哈希链 → 锚定; rid 全溯源
飞轮: outcome@τfb → θ 标定 | 人审 → KB | Ops 抽检 → 自检校准(偏差熔断+滞回)
V2 预留: KG 图谱 | Ops 拆独立审计体 | KG 攻击路径
```

关键数据流约定
感知层输出 alert；C 层唯一出口 C.Out(JSON)；D 层产出 ACT{lvl, ttl}；X 层回执走 outcome topic。
TI 归属 C 层（喂认知），不进入 S 层，避免污染原始遥测。
# 3. 分层规格
## 3.1 P 感知层（S）
职责：日志 / 流量 / EDR 遥测采集与降噪，输出归一化 alert。纯采集，不做研判。
约束：TI 不落地感知层；原始遥测只读、不可被处置链路回写。
时延预算：< 30ms（L0 主链）。
## 3.2 C 认知层
流水：Alert → Enrich（TI/CMDB/上下文拼装）→ LLM 疑点抽取 → Hyp 多假设并行 → Evidence 对撞 → Verdict（置信 + 证据链）。
接口签名：

```
C.Enrich(a:Alert) → Ctx{a, ti[], cmdb[], hist[], obs[]}      // 拼装器, 无 L
C.HypGen(ctx:Ctx) → H[≥2]                                     // 强制含 benign 假设
C.Evd(h:H, ctx)   → E{ev_id, src, conf, ts}                   // ev_id 须入库可溯
C.Collide(H, E)   → V{verdict, conf, evChain[], dissent?}     // 对撞出裁决
C.Out → JSON{rid, verdict, conf, ev[], hypo[], route, lvl}    // 唯一出口
```

硬约束（三条）：
schema 校验失败 → 重试 ≤2 → 降级规则引擎兜底。
ev[].id 不在证据库 → 整包拒收。
conf < τ 或 H 对撞平局 → abstain；弃权自动升 L1；弃权 ≠ 放行。
双模通道：
快道：告警降噪 / 归并，小模型 / 规则。
慢道：重研判 / 攻击链还原，大模型 + 多轮 ReAct。
按 CRIT 初筛分流；CRIT 字段缺失默认走慢道（fail-safe）。快道模型换型不动接口，Enrich 复用。
记忆：
短期 = 单事件上下文窗口；长期 = 写回 KB（向量 + 规则沉淀候选），人审后入库防污染。
反例机制（抗幻觉）：
显式生成“良性解释”对抗假设，Hyp 对撞结果喂 D 层门。
冲突 → 强制升 L1 人审；benign 解释被证据推翻也留痕，供 D 层门参考。
多 Agent 拆分：
V1 = 单体 LLM + 工具调用；Comp / Ops 降为角色 prompt，进程不拆。
拆分触发器（二选一）：ctx > 窗口，或 SLA 破线 → V1.5 先拆 Ops 为独立异步审计体。
Comp 与 Ops 同进程互锁，防自批自审。
## 3.3 D 决策层
门函数与变量标准化：

```
CF∈[0,1]  : 证据链支撑度 = evChain 加权和 × 假设区分度(benign 被推翻程度)
AV∈{1..5} : 资产价值 × 数据敏感度; CMDB 直查; 缺失 = 4(保守上浮)
RV∈{1..5} : 横向移动迹象 × 暴露面 × TI 活跃度
GR 否决集 : {核心生产, 数据删除, 外部可见面, 合规域} 任一命中 → L2 锁 HiTL, 分再高不放

Score = CF × (AV/5)^α × (RV/5)^β           // 初值 α=0.6, β=0.4
L2 判定 : Score ≥ θh ∧ CF ≥ θcf ∧ GR = ∅  → AutoBlock
Score < θl 或 CF < θcf_min 或 平局/弃权 → 升 L1
中间带 → L1 建议 + 置信展示

初值: θh=0.82, θcf=0.75, θcf_min=0.5; 按历史误报率滚动调; 调参行为人审留痕
```

反脆弱：
AV / RV 任一字段脏 → 降级走 L1。
Score 分布漂移监控，漂移 > σ 即冻结自动档，自动回滚 last-known-good。
outcome 回写带滞后窗 τfb ≈ 72h，防显影期早判污染飞轮；θ 调参快照版本化。
策略 DSL：

```
POLICY <id> v<n> [WIN t1~t2]:
WHEN <pred> -> ACT(a, lvl, ttl) PRI P0..P9 ONFAIL <fm>

pred := atom | pred ∧ pred | (pred)
atom := field op val | GATE() | KBASE(q, κ)
GATE() := score ≥ θh ∧ cf ≥ θcf ∧ gr = ∅ ∧ fresh(ev, τe)   // 原子谓词, 直读 C.Out
field := evt.* | ast.* | ti.* | hist.* | tm.*               // tm = 时间窗特征
ACT := OBSERVE | ESCALATE(L1) | TICKET | ISOLATE | BLOCK | QUARANTINE
// ACT 必带 lvl + ttl; ttl = 自动解除计时, 防永久阻断
fm  := DENY | DOWNGRADE(L1) | ABSTAIN                       // 谓词异常时走
```

注：PRI 显式枚举 P0..P9，P0 最高，禁裸整数，防实现倒挂。τe（事件级时效，分钟~小时）与 τfb（反馈级，天）分域，勿混用同参。
冲突消解四层：
GR 不在 DSL 内，硬编码 runtime 层，先于一切策略短路；策略永远盖不过 GR。
PRI 升序先命中先执行。
同 PRI 三级消解：特异性多者优先（atom 计数）→ 平局 deny-wins → 仍平 v 小者胜（保守旧版）。
编译期：shadow 检测（predA ⊃ predB ∧ PRI_B ≤ PRI_A → 告警，用 BDD/SAT 求解）；同 scope 矛盾 ACT（含 ttl 维度）拒绝上线。
版本化 + WIN 灰度窗；每次命中留痕 {pol_id, v, pred 指纹, 输入快照}，喂 θ 飞轮 + 审计。
上线环：编译 → 历史告警 replay 测命中率 / 误阻率 → replay 达标 → 1% 灰度 → 全量。replay 不过禁晋级。
## 3.4 X 执行层（PLAY 引擎）

```
任务图 : ACT → DAG{n: 原子动作, e: 依赖/条件}
状态机 : IDLE→PRECHECK→EXEC→VERIFY→COMMIT | ↘ROLLBACK
超时/异常任意态 → ROLLBACK; 幂等键 act_id + idem 防重
回滚语义 :
可逆(BLOCK/ISOLATE/QUARANTINE) → 生成 undo 句柄, TTL 到期 auto-release + 复核
不可逆(GR 域) → 前置 HiTL 确认, PLAY 只代执行, 不担责
VERIFY : 执行后取证比对(策略复查/遥测回读), 失败 → ROLLBACK + 升 L1 留痕
并发   : 资产级乐观锁, 同资产动作串行, 跨资产并行; 冲突 → 后到入队列
安全阀 : TTL 默认 24h 封顶; 告警风暴触发动作熔断(N 条/窗口 → 暂停 AutoLoop)
```

VERIFY 信源（V1 自采 + Ops 抽检，V1.5 随 Ops 拆分转独立）：
抽检加权：L2 及 GR 邻域 100% Ops 复核；L0/L1 随机 20%。
EXEC 取证快照入 append-only 哈希链，Ops 异步回放验签，破自证闭环。
偏差熔断：自检通过率与 Ops 抽检通过率分歧 > ε → 自检信源降级为仅供参考，VERIFY 全转 Ops 至修复；恢复加滞回（双窗口达标 + 人工确认）防抖。
回执矩阵（X ↔ K）：

```
回执 : ACK(收) → PEND(执行中) → DONE / FAIL / ROLLBACK(timeout 分派)
重试矩阵:
瞬态(网络/锁竞争)     → 指数退避 ×3, 幂等键 act_id + idem
持久(权限/对象不存在) → 不重试, FAIL + 升 L1
超时(无回执 > τ_ack)  → PLAY 侧查状态优先(非盲重试); 查得 DONE 照单; 查无 → ROLLBACK 兜底
ROLLBACK 失败         → 冻结资产 AutoLoop + 告警 P0, 人工接管
回执必带 : act_id + idem + state + err_class + 证据快照 ref(哈希链)
总线视角 : 回执走 outcome topic, outbox 同帧双写, 与直调结果同源
```

关键约定：超时 ≠ 失败，查状态优先于重试，防重复执行二次伤害。τ_ack ≥ X 段 EXEC 上限 + 网络余量；err_class 枚举固化入协议版本，与重试矩阵一一映射。
# 4. 横切机制
## 4.1 K 内核调度

```
总线 : topic 分层 {alert, ci, ti, cmd, outcome}; ≥1 语义投递; idem 键复用 act_id + idem
队列 : PQ 优先级 = lvl × AV_norm × 时效衰减; 老龄化升阶防饿死; 硬分带 L2 > L1 > L0 禁跨带
背压 : 深度 > θq → 慢道 Enrich 降频 / 批量推迟, L0 降采样; L2/GR 流永不 drop
熔断联动 : 风暴熔断触发时 PQ 只进不出; 恢复后按优先级限速泄洪
乱序 : 事件时间为主; late event(>τe) → 转慢道补裁决, 不阻塞主流
多消费者 : C/D/X 各订阅独立; X 动作回环 outcome topic, 闭环不跨层直调
```

补充约束：
AV_norm 仅用于带内排序，防高 AV 低危插队；L2 / L1 / L0 禁跨带。
熔断豁免 undo / TTL 解除类：停 AutoLoop 不停解除，否则风险悬置；熔断期到期 TTL 顺延（豁免类除外）。
总线保留窗 ≥ 7d 供 DSL replay 标定；≥1 投递 + idem = 处理器级等效 exact-once。
L0 降采样率入快照留痕，防飞轮统计失真。
直调 vs 总线（混合，四护栏）：
白名单仅 C.Out → D 单跳，禁扩面。
超时预算 ≈ 200ms；超时 / 失败 → 落总线重投 + abstain 升 L1（fail-safe）。
outbox 双写：直调结果同帧投 outcome，审计重放同源，防双账本。
运行时开关一键回纯总线；降级路径常演。
## 4.2 MEM 记忆与回写

```
回写类型 → 路径:
outcome(ev, act, res, @τfb 窗) → θ 标定集
人审裁决                       → KB: 准 → 向量 + 规则沉淀候选 / 驳 → 负样本库
benign 翻盘记录                → 硬规则缓存(相似告警直跳 L1)
TI 关系                        → C 层 Enrich 缓存, 不入规则库
```

防污染三闸：源白名单（仅人审结论 + 标注遥测）→ 去重 + 冲突检（与现存规则矛盾 → 搁置待议）→ 抽检 5% 看板。
规则沉淀：LLM 起草候选 → 人审 → 灰度入规则库，复用 DSL 的 WIN 灰度协议。
向量写入必带 rid + ev_id 全溯源，任一召回可回溯原始事件。KB 同样快照 + LKG，污染回滚与 θ 同协议。
沉淀粒度（簇级为主，实例级为例外）：

```
簇 := (tid, ast_class, benign_cls, sim ≥ κ)          // 同技术 + 资产类 + 良性解释类
沉淀门 : N ≥ 3 ∧ 裁决一致率 ≥ 0.9 ∧ 窗 τ_c = 7d
例外   : CF ≥ 0.95 ∧ 双签人审 → 实例级直升(GR 邻域加严)
负样本 : 同样簇级, 防膨胀
衰减   : 沉淀规则带复发计数, 窗内触发 < 2 → 降级回候选; 漂移检测 → 重校验
```

实例级例外计入簇统计；复发 < 2 同衰减。
## 4.3 GR 护栏

```
GR = 谓词集, 硬编码 runtime, 位置: D 求值前置短路 ∪ X 执行前最后闸
谓词表达 : 注册表制, 不入 DSL
GFn(arg) → bool | ERR          // ERR = 命中(fail-closed, GR 宁错杀不放行)
核心集: gr_core(asset ∈ 核心生产拓扑) | gr_del(act ∈ 删/改/覆写类)
| gr_ext(asset ∈ 外部暴露面) | gr_reg(数据 ∈ 合规域)
| gr_self(操作对象含自身/防护组件 ∪ 上游依赖, 防自断)

命中判定三态 :
HIT → 动作锁死 HiTL, Score/θh 失权; 打 gr_id 标签路由人审队列
MISS → 放行, 命中记录仍入哈希链(含 gr_id, 输入指纹, 判定时间)
ERR → 按 HIT 处理, 触发 GR 健康告警

审计链 : append-only 独立哈希链, 与 EXEC 快照链并行, 定期锚定(时间戳证)
变更   : 双人 + 双签, 改动入版本 diff, 演练期影子模式(判定不生效)先验
```

补充加固：
GR 谓词永不降级（防误伤疲劳型降级攻击）。误伤走 AL 临时豁免单：条目 = 双签 + TTL ≤ 24h + 留痕，到期自失效；同类 ≥ N 复发 → 聚合转正式白名单候选（复用 MEM 沉淀门）。
GR + HR 双向防御：GR 未命中但命中核心资产 → 强制 HiTL 复核兜底；HR 与 GR 同源（同一份内存预载表），禁双数据源漂移；HR 分流入审，低 Score 批量审防队列淹没。
gr_self 域 = 依赖闭包（直接对象 ∪ 上游依赖：TI 源 / KB 存储 / 日志管道），防间接自断；与 Comp/Ops 进程内互锁并存（异质冗余：逻辑层锁 vs 权限层闸）。
预载表刷新：版本戳 + 变更事件增量刷，刷新期 LKG 判定，原子切换；表缺 / 版本过期 > τ → ERR → 按 HIT，fail-closed 贯通。热点判定 < 5ms（内存预载，不查库）。
影子模式：影子 HIT 与实际放行对比表入上线评审；GR 变更必跑红队回归集（TC，固化版本化）。
# 5. 权限分级与门控

| 级别 | 语义 | 触发条件 | 执行路径 |
|---|---|---|---|
| L0 | 只读 / 自动观测 | 低风险、规则/小模型命中 | 快道自动，< 430ms |
| L1 | 建议 / 人工介入（HiTL） | 中间带、弃权、平局、AV/RV 脏 | 慢道 + 人审队列，异步 |
| L2 | 自动阻断 | Score ≥ θh ∧ CF ≥ θcf ∧ GR = ∅ | GR 前置校验 + AutoBlock |
| 锁定 | GR 命中 / 不可逆 | 命中否决集或 gr_* | 强制 HiTL，Score 失权 |

阈值归 D 层策略引擎定义与执行；策略本身由人审。可逆低门自动，不可逆（断核心生产 / 删数据）锁死 HiTL。
# 6. 端到端时序与 SLA 预算

```
L0 : P 感知 <30ms → C 快道 <150ms → D 求值 <50ms(直调含) → X 动作 <200ms  ≈ 430ms
L1 : 慢道 <8s → 人审异步(队列龄期 <30min) → X 执行 <1s
L2 : 前置同 L0 + GR 判定 <5ms → HiTL 确认 <15min → X 执行 + VERIFY <2s
超预算 : 各段 onTimeout → abstain 升 L1, 禁降级放行
SLA 拆解留痕 : 每段 p50/p95/p99 埋点, p95 破线告警; 破线持续 → 熔断回纯总线
尾部风险 : VERIFY + Ops 抽检异步, 不占主链预算, 单列 async SLA
```

预算细则：
各段预算 = 上限 × 0.8 为达标线，余量留抖动；abstain 升 L1 入队单列预算 < 100ms。
队列龄期分级：L1 普通 30min ｜ GR 邻域 + AL 豁免 15min ｜ P0（ROLLBACK 失败 / GR 健康告警）即时呼。超龄 → 值班升级路由，禁静默丢弃。
async SLA 数值化：Ops 抽检报告 ≤ 24h；θ 飞轮 τfb 窗内聚合。
埋点入快照；p95 持续破线联动 K 熔断降级。
